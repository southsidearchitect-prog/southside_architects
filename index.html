交付前確認

「範圍在外」不等於所有程序免審。來源可能有更新，正式申請仍須核對主管機關及案件適用版本。備份 JSON 含案件資訊與證據圖片，請自行妥善保管。

怎麼使用

  1. 填基本資料，選擇一個查核項目。
  2. 按「開啟官方來源」，在官方網站逐筆查地號。此版不自動輸入、下載或解驗證碼。
  3. 填分區／數值或結論、適用條件、來源及版本，附官方截圖。點截圖放置基地位置示意，不代表精確地籍界。
  4. 核實每筆地號後勾覆蓋確認，再改成「已核實」。不適用寫在結果欄，仍要附依據。未知保持待確認，網站失敗標受阻。
  5. 儲存至此瀏覽器；另匯出 JSON 作備份。更換瀏覽器／清除資料可能丟失本機儲存。
  6. 列印報告可在列印對話框另存 PDF，含完整結果及證據圖。原始官方文件請另外保留。
